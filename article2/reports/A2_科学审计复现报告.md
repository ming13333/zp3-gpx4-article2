## 2. 最严重发现：GSE91061 基因 ID 误用（8277 ≠ ZP3）

### 2.1 证据链

- GSE91061 表达矩阵（`GSE91061_BMS038109Sample.hg19KnownGene.fpkm.csv`）行名是 Entrez Gene ID。
- 三个脚本（`gse91061_zp3_analysis.py` v1、`gse91061_zp3_analysis_v2.py`、`gse91061_subtype_tmb_analysis.py`、`gse91061_molecular_subtype.py`）均写死 `zp3_entrez = 8277` 并注释"ZP3 的 Entrez Gene ID 是 8277"——**错误**。
- ZP3 的正确 Entrez ID = **7784**（已由 IMvigor210 官方 fData `entrez_id=7784, symbol=ZP3` 证实，与 NCBI Gene 一致）。
- 8277 对应另一基因（SP5 转录因子），其表达分布与 ZP3 不同：
  - Entrez 7784（真 ZP3）：mean≈1.27，median≈0.98，109/109 样本非零
  - Entrez 8277（误用）：mean≈1.72，median≈0.36，max 28.1（异常高点）

### 2.2 影响

| 分析 | 8277（错误） | 7784（正确） |
|---|---|---|
| GSE91061 全 105 样本 MWU | P=0.0023, r=−0.418 | P=0.0081, r=−0.363 |
| GSE91061 **Pre 基线 49 样本 MWU** | P=0.0339, r=−0.441 | **P=0.352, r=−0.195** |
| 亚型 Immune 内 | P=0.098 | **P=0.80** |
| 亚型 Keratin 内 | P=0.29 | **P=0.77** |
| Logistic 单变量 | P=0.25 | **P=0.45** (OR=0.72) |
| Logistic + IFN-γ / +Supp | P=0.25 / 0.26 | **P=0.52 / 0.58** |

**结论**：原稿 GSE91061 的"唯一阳性信号" = **错误基因 ID × 混入治疗期样本**双重伪影。修正后三队列主分析**全部阴性**（P=0.90 / 0.86 / 0.35），GSE91061 的阳性只在含 On-treatment 样本的敏感性分析中出现（P=0.008），任何 Pre 基线框架下均不显著。

### 2.3 对文章叙事的影响（正面）

- 修正后 A2 成为**更干净的三队列阴性结果**：无"阳性但脆弱"的尴尬解释，直接支撑"ZP3 不是可重复的独立 ICB 预测因子"。
- 新增一个审稿人视角的亮点：**"表观阳性信号"被证明是注释错误 + 时间点混合的人工产物**，强化多队列、基线样本、基因注释核验的方法学信息。
- IMvigor210（P=0.86, r=−0.015, TOST P=0.045）与 GSE78220（P=0.90）不受影响，阳性对照（TMB P=1.1×10⁻⁷；PD-L1 IHC P=1.2×10⁻³）不变。
