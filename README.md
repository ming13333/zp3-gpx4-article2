# ZP3–GPX4 Extracellular Immune-Suppression Axis — Article 2

## Scope
Standalone code & data repository for **Article 2** of the ZP3–GPX4 extracellular immune-suppression axis project (migration of the *Cell* 2026 GPX4–ZP3 axis into neuro-oncology / glioblastoma). This repository contains **only** the analysis code, frozen result tables, and submission-grade figures for Article 2.

## Directory structure
- `article2/` — manuscript-specific analyses
  - `scripts/`  — analysis scripts
  - `results/`  — **frozen result tables** (numerical truth; do not edit by hand)
  - `figures/`  — submission-grade SVG figures
  - `reports/`  — audit / reference-verification reports

- `shared/` — shared utilities (scripts, fetch, data) copied in for self-containment
- `LICENSE`, `requirements.txt`, `environment.yml`

## Reproducibility
Frozen tables under `article2/results/` are the source of truth. Regeneration scripts are in `article2/scripts/` and `shared/scripts/`. Per-script audit notes are embedded inline in the analysis scripts.

## Data Availability
- **Code:** https://github.com/ming13333/zp3-gpx4-article2 (this repository)
- **Archived snapshot (Zenodo DOI):** [10.5281/zenodo.22096061](https://doi.org/10.5281/zenodo.22096061) — concept DOI, always resolves to the latest archived version

## Frozen caliber for the ICB manuscript
The counts and permutation nulls reported in the immune checkpoint blockade manuscript all come from a
single frozen pipeline. The two calibers below are **not** interchangeable.
- `article2/scripts/transcriptome_audit_a2.py` — per-gene Mann–Whitney U test with tie **and continuity**
  correction. The frozen transcriptome-wide counts are A = 832, on-treatment-only = 4,015, pooled = 4,334,
  patient-level = 843. Removing the continuity correction changes them to 961 / 4,023 / 4,368 / 849.
- `article2/scripts/a2_v13_cluster_null_frozen.py` → `article2/results/a2_v13_cluster_null_frozen.json` —
  reproduces the frozen counts and builds the patient-cluster permutation nulls (500 permutations per
  framework) underlying Figure 6 and Supplementary Table S9.
- `article2/results/framework_cohort_masks_v2.json` — sample-to-framework assignment (A / B / C) and the
  response labels consumed by the permutation scripts.
- `article2/scripts/a2_cluster_permutation.py`, `a2_transcriptome_cluster_null.py` — the diagnostic-caliber
  exploratory versions kept for traceability only; their outputs are **superseded** by the frozen pipeline.

### Current (v14) permutation caliber — 10,000 permutations

The permutation counts in the submitted manuscript use **10,000** permutations, not 500. The authoritative
artefact is `article2/results/a2_v14_paired_bootstrap.json`; `article2/scripts/export_v14_frozen.py`
restates it in the v13 schema as `article2/results/a2_v14_cluster_null_frozen.json`, which is what
`article2/scripts/gen_fig6_v14_cluster_null.py` (Figure 6) and
`article2/scripts/build_supp_tables_v14.py` (Supplementary Tables S9 and S10) consume.

Fixed-42-patient isolation experiment (`part1_fixed42`), in which the patient set and the gene set are both
held fixed and only the analysis unit changes: pre-treatment 4.56%, on-treatment 4.52%, pooled **11.32%**.

Two uncertainties are reported rather than asserted. The excess-over-null difference between pooled and
on-treatment-only analyses is −1,517 (95% CI −3,423 to +149; stratified patient bootstrap, B = 600) and
−1,053 (jackknife SE 1,390; 95% CI −3,776 to +1,671); both intervals include zero, so the reduction in
signal recovery is labelled exploratory in the manuscript.
